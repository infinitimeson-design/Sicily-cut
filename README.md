# SICILY CUT

Official landing page for Sicily Cut.

---

## Brand

SICILY CUT is a modern premium barber studio with a minimal visual identity inspired by contemporary Italian aesthetics.

The website is intentionally designed as a fast-loading one-page digital business card.

---

## Tech

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks.

No dependencies.

No build tools.
